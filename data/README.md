# Facilities data

`facilities.json` is the browser-ready source of truth. `facilities.sqlite` is the
equivalent backend database generated by `scripts/build_facilities_sqlite.py`.

## Browser use

Load `facilities-db.js` before the application script:

```html
<script src="facilities-db.js"></script>
```

```js
const db = await FacilitiesDB.load();
const traumaCentres = db.find({ service: 'MTC' });
const urgentCare = db.find({ urgentOnly: true });
const openWalkInCare = db.find({ service: 'URGENT', openAt: new Date(), walkInOnly: true });
const suitableForChild = db.find({ service: 'URGENT', ageYears: 8 });
const nearestStrokeCentres = db.nearest(51.50, -0.12, { service: 'HASU', limit: 3 });
```

## SQLite examples

```sql
SELECT f.* FROM facilities f
JOIN facility_services s ON s.facility_id = f.id
WHERE s.service_code = 'UTC';

SELECT * FROM facilities WHERE urgent_care_type IS NOT NULL;

SELECT f.name, o.iso_weekday, o.opens, o.closes
FROM facilities f JOIN opening_periods o ON o.facility_id = f.id;
```

Opening hours and access rules change. Use the `verified_date` and `source_url`
fields and refresh operational data before production deployment. NHS 111/999
clinical triage must take precedence over nearest-distance routing.
